Privacy policy - Game Studio

Last updated: 18 November 2026

Who uses Game Studio

Game Studio is a personal desktop tool. It is used only by the owner of the PlayWithRohan channel, on his own computer. No other people use it.

What it uses

With my permission, Game Studio uses YouTube API Services to upload my own videos to my own channel, to set their titles, descriptions and publish times, and to read basic information about my channel. It also uses the Instagram API to post my own Reels to my own Instagram account.

Where data is kept

Sign-in tokens and settings are stored only on my own computer. Video details (titles, descriptions, times, links) are kept in my own Google Sheet. Nothing is sold or shared with anyone, and no information about other people is collected.

Removing access

Access can be removed at any time at myaccount.google.com/permissions (Google / YouTube) and in Facebook settings under Apps and websites (Instagram). Deleting the app's files from the computer removes all stored data.

YouTube and Google

Game Studio uses YouTube API Services. By using it, the YouTube Terms of Service apply: youtube.com/t/terms. See also the Google Privacy Policy: policies.google.com/privacy.
